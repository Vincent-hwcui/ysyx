# 阶段一：数字逻辑基础

## 学习目标

掌握数字电路基本概念，能独立完成组合逻辑和时序逻辑电路设计。

## 学习内容

- [ ] 布尔代数与基本逻辑门
- [ ] 组合逻辑电路（编码器、译码器、多路选择器、加法器）
- [ ] 时序逻辑电路（触发器、寄存器、计数器）
- [ ] 有限状态机 (FSM) 设计
- [ ] 存储器基础（SRAM、DRAM、ROM）
