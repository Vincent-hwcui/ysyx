# E 阶段：入门学习

> 掌握 C 语言、硬件描述语言、Linux 环境、RTL 仿真等基础技能，完成 PA1 并申请入学答辩。

## 阶段任务

| 任务 | 内容 | 预估时间 | 状态 |
|:---:|------|:---:|:---:|
| E1 | C 语言程序设计 | 20h | 🔲 |
| E2 | 硬件描述语言 | 20h | 🔲 |
| E3 | Linux 系统安装和基本使用 | 10h | 🔲 |
| E4 | 从 C 代码到二进制程序 | 10h | 🔲 |
| E5 | RTL 代码的仿真 | 20h | 🔲 |
| E6 | 完成 PA1 + 申请入学答辩 | 20h | 🔲 |

## 详细内容

### E1 — C 语言程序设计
- C 语言语法与指针、结构体
- 动态内存管理
- 为后续编写 NEMU 模拟器和测试程序打基础

### E2 — 硬件描述语言
- Verilog/Chisel 基础语法
- 组合逻辑与时序逻辑建模
- 模块化设计思想

### E3 — Linux 系统安装和基本使用
- 安装 Linux 环境（Ubuntu / WSL2）
- 掌握 Shell 基本命令
- 熟悉 vim/编辑器、Makefile

### E4 — 从 C 代码到二进制程序
- **C 程序的执行**：预处理 → 编译 → 汇编 → 链接
- **指令集模拟器**：理解模拟器如何逐条执行指令
- 理解程序是如何被翻译成机器码的

### E5 — RTL 代码的仿真（核心）
- **RTL 代码的仿真**：用 Verilator 等工具仿真 Verilog
- **逻辑综合**：RTL 到门级网表
- **Verilog 的 RTL 综合语义**：哪些代码可综合
- **标准单元库**：理解工艺库
- **物理设计**：布局布线基础

### E6 — 完成 PA1 + 申请入学答辩
- 完成 NEMU 的 PA1（Program Assignment 1）
- 提交入学答辩申请
- 通过后进入 D 阶段正式学习
