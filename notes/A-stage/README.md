# A 阶段：进阶学习

目标是让处理器能启动 Linux。官方这一段的预估时间还是 0，讲义也没出全，下面几项是从官方记录表的任务名推出来的，等讲义更新再补。

## 任务清单

| 序号 | 任务 |
|:---:|---|
| A1 | 乘除法器 |
| A2 | 系统调用和应用程序 |
| A3 | 虚存管理 |
| A4 | 特权级和 xv6 |
| A5 | 启动 Linux 和 Debian |
| A6 | 缓存进阶 |
| A7 | 分支预测进阶 |

## 每项大概在做什么

A1 是硬件乘除法器。前面 NEMU 里的乘除法靠软件模拟，这一项要把它做成硬件电路，会涉及 Booth 算法、阵列乘法器这类优化方法。

A2 是系统调用。实现 `ecall` 这条指令之后，用户程序就能通过系统调用跟操作系统打交道，而不只是自己算自己的。

A3 是虚存管理，做 MMU：页表怎么组织、TLB 怎么加速地址翻译、虚拟地址到物理地址的转换。这一项和考研 408 操作系统里的虚存、页表、TLB 是同一套内容。

A4 是特权级和 xv6。要先把 U/S/M 三个特权级做出来，才谈得上跑 xv6 这种真正的操作系统内核。

A5 是启动 Linux 内核、运行 Debian。到这一步处理器具备运行完整操作系统的能力，也是整个计划里比较有标志性的一项。

A6 是缓存进阶：多级缓存怎么组织、缓存一致性怎么保证。前面 B4 做的是简易 Cache，这一项接近真实处理器的复杂度。

A7 是分支预测进阶：BTB、BHT 这些动态预测结构怎么工作、预测器的准确率怎么量。

顺便记一笔：A3 到 A4 涉及的特权级和虚存，在 B 阶段是不做的，而这两块恰好是 408 操作系统的高频考点，需要另外单独补。
