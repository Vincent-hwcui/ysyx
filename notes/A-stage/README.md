## 详细内容

### A1 — 乘除法器
- 实现硬件乘除法器
- 乘法器优化（Booth 算法、阵列乘法器）

### A2 — 系统调用和应用程序
- 实现系统调用（ecall）
- 让用户程序通过系统调用与操作系统交互

### A3 — 虚存管理
- 实现 MMU（内存管理单元）
- 页表机制与 TLB
- 虚拟地址到物理地址转换

### A4 — 特权级和 xv6
- 实现 RISC-V 特权级（U/S/M 模式）
- 让 xv6 操作系统运行在自己的处理器上

### A5 — 启动 Linux 和 Debian
- 让自己的处理器启动 Linux 内核
- 运行 Debian 发行版
- 这是"处理器真正可用"的标志性成果

### A6 — 缓存进阶
- 多级缓存设计
- 缓存一致性
- 性能优化

### A7 — 分支预测进阶
- 动态分支预测（BTB、BHT）
- 分支预测器性能分析
