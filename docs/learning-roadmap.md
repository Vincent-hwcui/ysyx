# 学习路线图（官方 v24.07 版）

> 本路线图完全对齐"一生一芯"官方 v24.07 课程，按 **F → E → D → C → B → A → S** 七个阶段递进。
>
> 官方课程主页: <https://ysyx.oscc.cc/docs/2407/>

## 总览

```
F 前置学习 → E 入门 → D 正式学习 → C 处理器实现 → B SoC系统 → A 进阶 → S 高阶
```

| 阶段 | 名称 | 核心内容 | 关键成果 |
|:---:|------|---------|---------|
| **F** | 前置学习 | 数字逻辑、状态机、Logisim 处理器 | 迷你 RISC-V 处理器（Logisim） |
| **E** | 入门 | C语言、HDL、Linux、RTL 仿真 | 完成 PA1，申请入学答辩 |
| **D** | 正式学习 | NEMU、机器级表示、AM、迷你 RISC-V RTL | 用 RTL 实现迷你处理器 |
| **C** | 处理器实现 | 单周期 NPC、异常处理、RT-Thread | 处理器能跑 RT-Thread |
| **B** | SoC 系统 | 总线、SoC、时序、缓存、流水线 | 完整 SoC + 流水线处理器 |
| **A** | 进阶 | 虚存、特权级、xv6、Linux、缓存/分支预测 | 处理器启动 Linux/Debian |
| **S** | 高阶 | 待官方发布 | — |
