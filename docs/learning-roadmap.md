# 学习路线图

## 总览

```
数字逻辑基础 → 计算机组成原理 → RISC-V 指令集 → 硬件描述语言
                                                    ↓
流片 ← SoC 设计 ← CPU 核心设计 ← 仿真验证 ← 功能实现
```

---

## 阶段一：数字逻辑基础

**目标**: 掌握数字电路基本概念，能独立完成组合逻辑和时序逻辑电路设计。

**学习内容**:
- 布尔代数与逻辑门
- 组合逻辑电路（编码器、译码器、多路选择器、加法器等）
- 时序逻辑电路（触发器、寄存器、计数器、状态机）
- 存储器基础（SRAM、DRAM、ROM）

**实践任务**:
- [ ] 用 Verilog 实现基本组合逻辑电路
- [ ] 用 Verilog 实现有限状态机 (FSM)
- [ ] 完成数字电路仿真验证

---

## 阶段二：计算机组成原理

**目标**: 理解计算机硬件系统的工作原理，掌握 CPU 的基本结构。

**学习内容**:
- 计算机系统层次结构
- 数据的表示与运算（补码、浮点数）
- 指令系统设计原理
- CPU 数据通路与控制器设计
- 存储系统（Cache、虚拟存储）
- I/O 系统与总线

**实践任务**:
- [ ] 理解单周期/多周期/流水线 CPU 的区别
- [ ] 画出一个基本 CPU 的数据通路图
- [ ] 分析流水线冒险（数据冒险、控制冒险、结构冒险）

---

## 阶段三：RISC-V 指令集架构

**目标**: 深入理解 RISC-V 指令集，能编写和运行 RISC-V 汇编程序。

**学习内容**:
- RISC-V 架构概述与设计哲学
- RV32I 基本整数指令集
- 寻址模式与指令格式（R/I/S/B/U/J 型）
- 函数调用约定与栈帧管理
- 扩展指令集（M 乘法、F 浮点等）

**实践任务**:
- [ ] 安装 RISC-V 工具链
- [ ] 编写 RISC-V 汇编程序（排序、斐波那契等）
- [ ] 使用模拟器（Spike/QEMU）运行汇编程序
- [ ] 阅读并理解 RISC-V 规范文档

---

## 阶段四：硬件描述语言 (Verilog/Chisel)

**目标**: 熟练使用 Verilog 或 Chisel 进行硬件描述和建模。

**学习内容**:
- Verilog 语法基础（模块、端口、数据类型）
- 组合逻辑建模（assign、always @(*)）
- 时序逻辑建模（always @(posedge clk)）
- Testbench 编写与仿真
- Chisel 基础（如选择 Chisel 路线）

**实践任务**:
- [ ] 实现 ALU (算术逻辑单元)
- [ ] 实现寄存器堆 (Register File)
- [ ] 实现基本存储器模型
- [ ] 编写 Testbench 并使用 GTKWave 查看波形

---

## 阶段五：CPU 核心设计

**目标**: 独立设计并实现一个 RISC-V CPU 核心。

**学习内容**:
- 单周期 CPU 设计与实现
- 五级流水线 CPU 设计
- 冒险检测与处理（转发 Forwarding、停顿 Stall、分支预测）
- CPU 性能分析与优化

**实践任务**:
- [ ] 实现单周期 RISC-V CPU (支持 RV32I 核心指令)
- [ ] 通过指令级测试
- [ ] 扩展为五级流水线设计
- [ ] 实现数据转发和分支预测
- [ ] 运行实际程序（如 Coremark 性能测试）

---

## 阶段六：SoC 系统设计

**目标**: 将 CPU 核心集成到完整的 SoC 系统中。

**学习内容**:
- 总线协议（AXI/APB/AHB）
- 内存映射与地址空间分配
- 外设接口设计（UART、SPI、GPIO、Timer）
- 中断控制器 (PLIC/CLINT)
- DMA 与存储系统

**实践任务**:
- [ ] 设计 SoC 顶层模块
- [ ] 实现 UART 串口通信
- [ ] 实现 SPI 接口（连接 Flash 等）
- [ ] 在 FPGA 上进行验证

---

## 阶段七：流片 (Tape-out)

**目标**: 完成芯片的物理设计并提交流片。

**学习内容**:
- 集成电路物理设计流程
- 综合 (Synthesis)
- 布局布线 (Place & Route)
- 时序分析 (STA)
- DRC/LVS 物理验证
- GDSII 生成与 Tape-out

**实践任务**:
- [ ] 完成 RTL 综合
- [ ] 完成布局布线
- [ ] 通过时序分析
- [ ] 通过 DRC/LVS 验证
- [ ] 生成 GDSII 并提交流片
- [ ] 收到芯片后进行功能验证

---

## 时间规划建议

| 阶段 | 建议时长 | 备注 |
|:---:|:---:|------|
| 01 - 数字逻辑 | 2-3 周 | 打好基础 |
| 02 - 计算机组成 | 2-3 周 | 理论为主 |
| 03 - RISC-V ISA | 1-2 周 | 动手写汇编 |
| 04 - HDL | 2-3 周 | 多写多练 |
| 05 - CPU 设计 | 4-6 周 | 核心阶段 |
| 06 - SoC 设计 | 3-4 周 | 系统集成 |
| 07 - 流片 | 4-8 周 | 物理设计 |
